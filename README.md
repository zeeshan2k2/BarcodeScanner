# BarcodeScanner  

**BarcodeScanner** is a SwiftUI-based iOS application built to explore barcode and QR code scanning using the device camera.

---

## Features  

- Barcode and QR code scanning  
- Camera integration using AVFoundation  
- Real-time scan detection  
- Simple and focused scanning interface  
- State-driven UI updates  

---

## Tech Stack  

- **Language:** Swift  
- **Framework:** SwiftUI  
- **Camera Framework:** AVFoundation  
- **Architecture:** MVVM
